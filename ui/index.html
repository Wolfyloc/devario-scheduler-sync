Devario Scheduler Sync v0.2

Automatically activate CoolerControl Modes when the sched-ext scheduler changes.

Scheduler mappings

The plugin discovers schedulers using scxcli list every 30 seconds. Reopen this page or use Refresh to see new entries.

Unmapped schedulers leave the current cooling Mode unchanged. Unavailable catalog entries are shown but cannot currently be activated. API token is stored separately.
