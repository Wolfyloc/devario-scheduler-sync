Devario Scheduler Sync v0.2

Automatically switch CoolerControl cooling Modes when the active sched-ext CPU scheduler changes.

General Settings

How often the plugin checks for scheduler changes, in seconds. Allowed range: 1–60 seconds.

Scheduler Mode Mappings

Choose which CoolerControl Mode should activate when each CPU scheduler is running. Select "No change" to keep the current cooling Mode.

Available schedulers are discovered automatically every 30 seconds. Use Refresh Scheduler List to reload the latest discovered entries.

Apply Changes

Save your settings to apply updated scheduler mappings. Refreshing the scheduler list does not save changes.

Uninstalled schedulers may appear in the catalog but cannot be activated until installed. API credentials are stored separately.
